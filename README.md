# K-Global

K-Global est une maquette de navigateur / moteur de recherche avec un arrière-plan nébuleux.

## Fonctionnalités

- Interface en français avec ambiance espace, étoiles et nébuleuse animée.
- Barre de recherche centrale K-Global.
- Résultats affichés dans la page K-Global sous forme de raccourcis Google.
- Clic sur un résultat : ouverture de Google avec la recherche demandée.
- Pour revenir sur K-Global après Google, utilisez le bouton retour du navigateur.

> Note : une page web simple ne peut pas copier automatiquement les vrais résultats Google sans API officielle. Cette version crée donc une façade de résultats qui envoie vers Google.

## Lancer localement

```bash
python3 -m http.server 4173
```

Puis ouvrez `http://localhost:4173`.
